- [Upgrade from 1.x to the 2.0.0 release](docs/2.0/UPGRADE.md)

Existing 1.1 Git tags retain their published code. The `^1.1` and `^1.1.39`
Composer constraints exclude 2.0. An upgrade to 2.0 requires deliberately selecting
that major version and reviewing the changes to installation, refresh and seeding.
